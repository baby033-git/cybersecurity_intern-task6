# 💻 Cybersecurity Internship – Task 6

### 🧠 Task Name:
**Create a Strong Password and Evaluate Its Strength**

---

### 📋 Steps I Followed:

1. Opened a free **Password Strength Checker** website (like [passwordmeter.com](https://passwordmeter.com)).
2. Created 4–5 example passwords (some short, some long, some with symbols).
3. Tested each password on the website and checked the **score and feedback**.
4. Took **screenshots** of the results.
5. Wrote down what makes each password strong or weak.
6. Created a small **report** (PDF or text) with screenshots and notes.
7. Uploaded everything to this GitHub repository.

---

### 📂 Files in This Repository:

- `passwords.txt` → Contains my password test results and notes.  
- `screenshots/` → Folder with screenshots of password strength results.  
- `README.md` → This file explaining my work.

---

### 🔐 What I Learned:

- Passwords become stronger when they are **long**, include **symbols**, **numbers**, and **uppercase + lowercase** letters.  
- **Short or common words** are easy to guess.  
- **Passphrases** (like “BlueSky!Morning2025”) are strong and easier to remember.  
- Tools like **Password Managers** help in storing strong passwords safely.  
- **Never use the same password** for multiple accounts.
